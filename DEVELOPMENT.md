# Development

`install` links `AGENTS.md` and every skill into every session, so they MUST
hold in every repository.

Instructions and skills MUST NOT depend on a feature only one coding agent
has; what an agent requires beyond `AGENTS.md` and `.agents/skills/` MUST stay
in links and `install`.

A skill MUST name its files relative to its own directory. Documentation that
changes upstream MUST NOT be copied here; a skill retrieves it.
